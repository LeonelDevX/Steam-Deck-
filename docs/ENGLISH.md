# RemoteLauncher — English

RemoteLauncher aims to offer a free, Steam-Deck-like remote gaming experience using devices you already own.

**Not a Steam Deck emulator or a source of free paid games.** A compatible Windows gaming PC, owned games and networking may be required. Current binaries have not been independently tested.

## Platforms

- Windows x64: `RemoteLauncher-Setup-1.0.10-x64.exe`
- Android: `RemoteLauncher-Android-release.apk`
- iOS: `RemoteLauncher.ipa` (requires an appropriate signing/install method)

The files have not yet been published as verified GitHub release assets. Check [Releases](../../releases) for future verified downloads.

## Setup

Install the Windows host using the official release installer, install the matching Android app or properly signed iOS app, and follow the in-app connection flow. Exact compatibility and connection steps remain to be validated.
