# RemoteLauncher

**Kostenloses Remote-Gaming für Windows, Android und iOS.**

RemoteLauncher ist ein Community-Projekt für ein Steam-Deck-ähnliches Spielerlebnis auf Geräten, die du bereits besitzt. Die Idee: Spiele von deinem eigenen Windows-PC auf ein Mobilgerät streamen, statt zusätzliche Handheld-Hardware zu kaufen.

> **Wichtig:** Dies ist kein Steam Deck und keine Möglichkeit, kostenpflichtige Spiele gratis zu erhalten. Ein geeigneter Gaming-PC, eigene Spiele und eine funktionierende Netzwerkverbindung können erforderlich sein. Die hochgeladenen Builds sind noch nicht unabhängig auf Funktion oder Sicherheit geprüft.

## Downloads

Die folgenden Installationsdateien sind vorhanden, aber **noch nicht als GitHub-Release veröffentlicht**:

| Plattform | Datei | Hinweis |
| --- | --- | --- |
| Windows x64 | `RemoteLauncher-Setup-1.0.10-x64.exe` | Windows-Installationsprogramm |
| Android | `RemoteLauncher-Android-release.apk` | Android-Paket |
| iOS | `RemoteLauncher.ipa` | IPA; Installation und Signierung können zusätzliche Voraussetzungen haben |

Sobald verifizierte Releases veröffentlicht sind, findest du sie unter [Releases](../../releases). **Lade keine Dateien von inoffiziellen Mirror-Seiten herunter.**

## Installation

### Windows

1. Lade die passende x64-Setup-Datei aus einem offiziellen Release herunter.
2. Prüfe Herausgeber und Dateiintegrität, bevor du sie ausführst.
3. Starte das Setup und folge dem Installationsdialog.
4. Konfiguriere die Verbindung gemäß den Einstellungen in der App.

### Android

1. Lade die APK aus einem offiziellen Release herunter.
2. Öffne sie auf deinem Android-Gerät und erlaube die Installation aus dieser Quelle nur bei Bedarf.
3. Starte die App und richte die Verbindung ein.

### iOS

Eine IPA lässt sich nicht wie eine APK direkt installieren. Sie benötigt eine geeignete Signierungs- und Installationsmethode. Die konkrete Kompatibilität dieser IPA wurde noch nicht bestätigt.

## Was ist kostenlos?

Die Projektidee sieht keine Abo-Gebühren für RemoteLauncher vor. **Spiele, Gaming-PC, Internet, Strom und gegebenenfalls Apple-Signierung sind nicht automatisch kostenlos.** Ob die vorliegenden Builds vollständig kostenlos nutzbar sind, muss noch geprüft werden.

## Projektstatus

**Frühe öffentliche Projektseite.** Die drei Builds wurden bereitgestellt, aber weder ihre interne Architektur noch Streaming-Protokoll, Controller-Unterstützung, unterstützte Betriebssystemversionen oder Netzwerkfunktionen sind verifiziert. Daher werden diese Funktionen hier nicht als gesichert beworben.
